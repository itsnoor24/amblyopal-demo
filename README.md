# AmblyoPal 🎮 

### Interactive Vision Games for iOS

AmblyoPal is an iOS app featuring a collection of interactive dichoptic games designed for use with red-blue anaglyph glasses. 


## Requirements

AmblyoPal requires **red-blue anaglyph glasses** to play the games as intended.

I used [these anaglyph glasses](https://www.amazon.ca/dp/B01ANJXCU2) during development and testing.
